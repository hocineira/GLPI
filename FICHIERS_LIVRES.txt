📦 SCRIPTS D'INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. install_glpi.sh (⭐ PRINCIPAL)
   ├─ Script d'installation complète de GLPI 11.0.0
   ├─ Configure le DNS pour l'intégration LDAPS
   ├─ Installe Apache, MariaDB, PHP et extensions
   ├─ Configure la base de données
   ├─ Installe et configure GLPI
   ├─ Configure Apache avec VirtualHost
   └─ Teste la résolution DNS

   📝 Usage: sudo ./install_glpi.sh

2. configure_dns.sh
   ├─ Script de configuration DNS uniquement
   ├─ Configure /etc/systemd/resolved.conf
   ├─ Prépare le système pour l'intégration LDAPS
   └─ Teste la résolution DNS et connectivité AD

   📝 Usage: sudo ./configure_dns.sh

3. check_prerequisites.sh
   ├─ Script de vérification des prérequis
   ├─ Vérifie le système d'exploitation
   ├─ Vérifie l'espace disque et la mémoire
   ├─ Vérifie la connectivité réseau
   └─ Vérifie les ports et logiciels existants

   📝 Usage: sudo ./check_prerequisites.sh

🎯 ORDRE D'UTILISATION RECOMMANDÉ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Étape 1 : Lire la documentation
   → Commencez par QUICKSTART.md pour une vue d'ensemble
   → Consultez README_GLPI.md pour les détails complets

Étape 2 : Vérifier les prérequis
   → Exécutez: sudo ./check_prerequisites.sh

Étape 3 : Préparer les informations nécessaires
   → Adresse IP du serveur GLPI
   → Mot de passe pour la base de données
   → Adresse IP du serveur DNS (AD)
   → Nom de domaine
   → FQDN du serveur AD

Étape 4 : Installer GLPI
   → Exécutez: sudo ./install_glpi.sh
   → Suivez les instructions à l'écran

Étape 5 : Configuration web
   → Accédez à http://VOTRE_IP/glpi
   → Terminez l'installation via l'interface web

Étape 6 : Configurer LDAPS
   → Consultez LDAPS_CONFIGURATION.md
   → Configurez dans GLPI: Configuration > Authentification > LDAP

├─ Ubuntu: 24.04 LTS
├─ GLPI: 11.0.0
├─ Apache: 2.4.63
├─ MariaDB: 10.11.13
└─ PHP: 8.3.x

Fichier de configuration DNS:

Répertoire d'installation GLPI:
└─ /var/www/html/glpi/

Base de données:
├─ Nom: glpidb
└─ Utilisateur: glpi

Ports utilisés:
├─ 80 (HTTP)
├─ 443 (HTTPS)
├─ 3306 (MariaDB)
└─ 636 (LDAPS)

⚠️  NOTES IMPORTANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Tous les scripts DOIVENT être exécutés avec les privilèges root (sudo)

2. Le script d'installation crée automatiquement une sauvegarde de la 
   configuration DNS existante

3. Les scripts suivent EXACTEMENT la procédure documentée dans:
   Procédure_GLPI_V11_2025.pdf (de IRATNI Hocine)

4. Changez IMPÉRATIVEMENT les mots de passe par défaut de GLPI après 
   la première connexion

5. Pour l'intégration LDAPS, assurez-vous que:
   - Le serveur AD est accessible
   - Le port 636 (LDAPS) est ouvert
   - La résolution DNS fonctionne correctement
