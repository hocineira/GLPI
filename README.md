# Script d'installation GLPI 11.0.0

Script automatisé pour l'installation de GLPI 11.0.0 sur Ubuntu 24.04 LTS avec préparation pour l'intégration Active Directory (LDAPS).

## 🚀 Installation rapide

```bash
# Cloner le dépôt
git clone <votre-url-repo>
cd <nom-du-repo>

# Rendre le script exécutable
chmod +x install_glpi.sh

# Lancer l'installation
sudo ./install_glpi.sh
```

## 📋 Fonctionnalités

- Installation complète de GLPI 11.0.0
- Configuration Apache, MariaDB, PHP 8.3
- Configuration DNS pour Active Directory (optionnel)
- Tests de résolution DNS
- Installation interactive
